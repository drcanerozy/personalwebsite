Sports nutrition-based recommendation systems are composed of software, dashboard, and mobile applications which are developed based on machine learning and deep learning algorithms. These works help to build an intelligent recommender system in an effective way.To make a prediction and to suggest the foods to the players, a model should be deployed. The pre-processed data is called and the model is built with LSTM and further extended with LSTM with GRU. The proposed system is deployed with LSTM and LSTM with GRU. In both models, sequential data is declared for defining the model, and the layers are added to it.  Both models use an activation function for cell state and node output but LSTM with GRU uses an update gate to train the model in an efficient and simple way. In our prediction, the input variables are age, height, and weight. The training set is used to fit the model for predicting results and the testing set is to evaluate the performance of the model.
